# Промо-баннер «−10% за заявку» — дизайн

**Дата:** 2026-06-18
**Статус:** утверждён, готов к плану реализации

## Цель

Тонкая рекламная полоса над шапкой сайта, сообщающая: клиентам, оставившим
заявку на сайте, — скидка 10% на строительство бассейна. Полоса целиком
кликабельна (открывает форму заявки), закрывается крестиком, после закрытия
не показывается до конца сессии.

## Решения (зафиксированы при брейншторме)

| Вопрос | Решение |
|---|---|
| Размещение | Полоса **над** фикс-шапкой; шапка и контент сдвигаются вниз на её высоту |
| Действие по клику | Клик по **всей полосе** (кроме крестика) открывает форму заявки |
| Память о закрытии | **Только на сессию** — `sessionStorage`, при новом визите показывается снова |
| Страницы | 4 статические (`index`, `catalog`, `models`, `portfolio`) **+ `/pool`** (`views/pool.ejs`) |
| Аналитика | Доп. цель Метрики `promo_click` при клике + штатная `form_opened` от формы |

## Архитектура

Изолированный модуль по образцу существующего `cookie-banner` (свой CSS + свой
JS-IIFE, вставляющий узел в `body`). `css/style.css` не редактируем.

**Новые файлы:**
- `css/promo-banner.css`
- `js/promo-banner.js`

**Правки существующих:**
- `js/quiz.js` — экспорт `window.openQuiz = openQuiz;`
- `js/consult.js` — экспорт `window.openConsult = openConsult;`
- `index.html`, `catalog.html`, `models.html`, `portfolio.html`, `views/pool.ejs`
  — подключить `<link>` в `<head>` и `<script defer>` рядом с `cookie-banner`.

## 1. Раскладка и сосуществование с фикс-шапкой

Шапка `.header` сейчас `position: fixed; top:0; height:60px; z-index:100`.
Контент отступает от неё собственными `padding-top` секций (hero: 80–88px).
Скролл-скрытие шапки — класс `body.header-hidden` (motion.js) →
`transform: translateY(-100%)`.

Вводим CSS-переменную `--promo-h` (по умолчанию `0`). Все правила — в
`promo-banner.css` (грузится после `style.css`, та же специфичность → берёт верх;
при `--promo-h:0` поведение 1-в-1 как сейчас):

```css
:root { --promo-h: 0px; }
.header { top: var(--promo-h); transition: top .3s var(--ease-out, ease); }
body    { padding-top: var(--promo-h); transition: padding-top .3s; }
```

- Полоса: `position: fixed; top:0; left:0; right:0; height:<h>; z-index:101`
  (выше шапки z=100).
- Когда баннер активен, JS ставит `--promo-h` = высота полосы
  (≈38px десктоп / ≈52px моб., если текст в 2 строки). На мобиле высоту берём
  из реального `offsetHeight` полосы после вставки.
- `body { padding-top }` сдвигает весь контент вниз ровно на высоту полосы;
  существующие `padding-top` секций уже учитывают 60px шапки → ничего не наедет.
- Скролл-скрытие шапки работает как раньше: шапка прячется `translateY(-100%)`
  за полосой (z ниже). Полоса остаётся тонкой сверху. **Полосу при скролле не
  прячем** (YAGNI).
- При закрытии `--promo-h → 0`, `top`/`padding-top` плавно возвращают шапку и
  контент на место.

## 2. Поведение (`js/promo-banner.js`)

IIFE, `defer`. По образцу `cookie-banner.js`.

1. **Гейт показа:** если `sessionStorage.getItem('promoClosed') === '1'` — выходим,
   ничего не вставляем (`--promo-h` остаётся 0). `try/catch` вокруг storage — при
   недоступности показываем.
2. **Вставка:** создаём узел полосы, добавляем в `body`. Меряем `offsetHeight`,
   ставим `--promo-h`. Через ~600ms добавляем класс `is-visible` (slide-down),
   чтобы не «бить по глазам» на загрузке.
3. **Клик по полосе** (кроме крестика):
   - шлём цель: `window.ym && ym(100792239, 'reachGoal', 'promo_click')`;
   - открываем форму: `if (typeof window.openQuiz === 'function') window.openQuiz();
     else if (typeof window.openConsult === 'function') window.openConsult();`.
   - На 4 статических страницах сработает квиз; на `/pool` (нет quiz.js, есть
     consult.js) — форма консультации. Обе шлют `form_opened` сами.
4. **Клик по крестику** (`stopPropagation`, чтобы не открыть форму):
   `sessionStorage.setItem('promoClosed','1')`, снимаем `is-visible` (slide-up),
   `--promo-h → 0`; после завершения transition (~320ms) удаляем узел.

**Доступность:** полоса `role="button"`, `tabindex="0"`, реагирует на Enter/Space;
крестик — отдельная `<button aria-label="Закрыть">`. `prefers-reduced-motion` —
без анимаций (мгновенное появление/исчезновение), как принято в проекте (motion.js).

## 3. Контент и оформление

- Текст: 🎁 **«Оставьте заявку на сайте — скидка 10% на строительство бассейна»**.
  На узких экранах допускается перенос в 2 строки / сокращённый вариант
  «🎁 −10% на строительство при заявке с сайта». Точную формулировку
  подтверждаем при реализации.
- Крестик `×` справа.
- Цвета — через переменные `theme.css`; корректный контраст в светлой (по
  умолчанию) и тёмной (`data-theme="pool"`) темах. Акцентный фон, контрастный
  текст. Иконки/ховеры — в духе существующих компонентов.

## Тестирование (ручная проверка после реализации)

1. Главная: полоса появляется сверху, шапка/контент сдвинуты, ничего не
   перекрыто; в светлой и тёмной теме читаемо.
2. Клик по полосе → открывается квиз; в Метрике (или консоли `ym`) — `promo_click`
   + `form_opened`.
3. Крестик → полоса уезжает, контент возвращается; `sessionStorage.promoClosed=1`;
   обновление страницы — баннера нет; новая сессия (новая вкладка после закрытия
   браузера / очистка sessionStorage) — снова есть.
4. Скролл вниз: шапка прячется, полоса остаётся, верстка не прыгает.
5. `/pool`: полоса есть, клик открывает форму консультации, шлёт `promo_click`.
6. Мобайл ≤480px: высота полосы корректная, текст не обрезан, тап-таргеты ок.

## Вне рамок (YAGNI)

- Скрытие полосы при скролле.
- Срок «не показывать» дольше сессии / cron на акцию.
- Серверная выдача/отключение баннера (правится в коде, акция временная).
- A/B текста.
