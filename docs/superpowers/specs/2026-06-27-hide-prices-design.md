# Скрыть цены на сайте → «Цена по запросу»

**Дата:** 2026-06-27
**Статус:** утверждён

## Цель

Убрать с публичного сайта все видимые цены и показывать вместо суммы текст
«Цена по запросу». Данные о ценах в БД/API/фидах сохраняются.

## Подход

Менять только уровень отображения. В каждой точке вывода вместо суммы
показываем константу «Цена по запросу». Источник данных (`m.price`,
`model.price`) не трогаем — это минимально, обратимо и не ломает рекламу/SEO.

Отвергнутые варианты:
- Вырезать цену из API/данных — ломает фид и админку.
- CSS `display:none` — цена остаётся в исходном коде, нет текста «по запросу».

## Не трогаем

- **Админка** (`views/models/index.ejs`, `form.ejs`) — цены нужны для управления.
- **Квиз/CTA «Рассчитать стоимость»** — остаётся (решение пользователя).
- **schema.org разметка** и **`/feed.xml`** (`routes/catalog.js`, `lib/price.js`) —
  остаются, чтобы не ломать Яндекс.Директ и SEO-сниппеты (решение пользователя).
- **`lib/price.js`** и `test/price.test.js` — без изменений.

## Проверка

- Открыть каталог, карточки моделей, страницу модели, модалку галереи —
  везде «Цена по запросу», вёрстка не сломана.
- `npm test` — зелёный (тесты `parsePrice` не затронуты).
- Фид `/feed.xml` и schema.org по-прежнему содержат реальные цены.
